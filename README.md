# EMBERQUEST — 灰の旅人 / v4

現実の任務を一つ果たすたび、騎士が道を切り開くタスクRPG。
HTMLだけでなく、ゲーム計算・タスク管理・保存・描画・UIを分けたJavaScript、CSS、ビルドスクリプト、テストを含みます。

## まず動かす

- `dist/index.html`：JavaScript・CSSを別ファイルで読み込む通常版。
- `dist/emberquest-standalone.html`：すべてを含む単体HTML版。

ZIPをフォルダごと展開してから、いずれかをブラウザで開いてください。
通常版は `dist/` 内のJS・CSSも必要です。HTMLだけを別の場所へ移す場合は単体版を使います。
外部画像、外部フォント、npmパッケージ、APIキー、アカウント登録は不要です。

ローカルサーバーを使う場合：

```sh
python3 -m http.server 8080 --directory dist
```

ブラウザで `http://localhost:8080` を開きます。iPhoneではWebサイトとして開いて使うのが簡単です。
この版にはホーム画面用のPWAインストール・オフラインキャッシュ・端末間同期は含みません。

## ソース構成

| ファイル | 役割 |
| --- | --- |
| `src/template.html` | HTMLの構造、フォーム、ダイアログ |
| `src/style.css` | PC／スマホ対応のダークファンタジーUI |
| `src/game.js` | 遭遇、戦闘、成長、2系統の武器、強化、報酬、取消、バックアップ検証 |
| `src/tasks.js` | 時間に応じた作業量提案、日付計算、毎日／毎週の繰り返し |
| `src/storage.js` | 自動保存、JSON書き出し、旧版の読込と復元 |
| `src/art.js` | オリジナルSVGの主人公、武器、敵、背景、アイコン |
| `src/app.js` | 主目標、集中画面、演出、装備比較、日次まとめなどのUI操作 |
| `src/migration-v3.js` | 旧版の報酬計算を正確に読み取る移行用コード |
| `build.py` | 分割版と単体HTML版の両方を生成 |
| `tests/game.test.cjs` | 遭遇・報酬・武器・取消・繰り返し・進行速度のテスト |
| `tests/storage.test.cjs` | JSON保存／復元、旧版移行、壊れたデータの拒否をテスト |
| `package.json` | 依存パッケージなしのビルド／テストコマンド |

`src/template.html` を直接開いても、同じフォルダのJS／CSSで動作します。
更新後の配布ファイルは、以下で作り直します。

```sh
python3 build.py
node --test tests/*.test.cjs
```

Node.js 18以上、Python 3を使用。`npm install` は不要です。
`npm run build` / `npm test` も使えます。

## 使い方

1. これから行う任務を名前＋目安時間で登録。テンプレートも使用可能。
2. 今日できる成果を主目標に選ぶ。初回の今日の任務は自動で主目標になります。
3. 「取りかかる」から、最初の一歩だけを表示する集中画面へ。
4. 現実で予定した工程を進め、「今回の工程を完了する」。課題全体の完成は不要です。
5. 遭遇の突破・素材回収・鍛造が積み重なる。装備画面では鍛造前後の姿を比較できます。
6. 「本日の遠征を終える」で現実と冒険の成果を確認。「明日の一歩」は翌日の主目標として予定できます。

タイマーは任意。時間切れだけでは自動完了しません。
遠征終了は強制停止ではありません。任務に再び着手すれば遠征を再開し、記録は残ります。

## 冒険の変更点

### 遭遇を順番に突破

第一章は「灰の斥候 → 廃営地の資材 → 鉄骸の衛兵 → 城門の番人」。
敵のHPを削り切ると、その場で次の遭遇へ進みます。探索距離という別のクリア条件はありません。
資材の場所は次の任務で回収。通常戦闘やボスとの違いが演出と結果にも反映されます。
最後のボスを倒すと、門が開き、烽火が灯り、次の地域が解放されます。
踏破済み地域は素材の再探索になり、経験値は半分。敵や探索距離は復活しません。

### 好きな武器を鍛え続ける

大剣と双剣の2系統。同じ強化段階なら総ダメージは同じです。
大剣は一撃、双剣は三つに分割した命中で表現し、合計値が一致します。
強化は一方を次の上位武器に置き換える方式ではありません。両方を独立に何度でも強化できます。
武器名・輪郭・色・金属の輝きで初期～上位段階を表現し、上位段階以降も強化数が伸びます。
攻撃力は `16 + レベル × 2 + 強化段階 × 5`。武器の強化コストは段階に応じて増えます。

### 通常報酬と主目標

目安時間10分以下は行動力1、40分以下は2、それ以上は4を提案します。詳細で変更可能。
主目標の追加報酬は1日1回、鉄片2個＋熾火1個。
欲しい装備への確定進行が中心で、ランダムドロップに依存しません。
プロジェクトは工程をまとめる単位。各工程が素材を獲得し、親プロジェクトは称号の節目です。

### 進行速度の仮説

テストでは、1日3件（25分・25分・10分）、最初の任務を主目標にし、素材が揃い次第大剣を強化する条件で、初強化2日目・第一章踏破8日目でした。
これは計算上の調整値です。生産性や継続率の検証結果ではありません。
実際の利用量で前後し、休んでもHP・素材・装備・成長は減りません。

## 毎日・毎週の任務

繰り返しはローカル日付で管理。週次任務は登録した曜日を維持します。
次の回は、その日付になってからアプリを開いたときに作成します。
数日休んでも、過去の回を全部複製せず現在の回を一つ作成。以前の未実施は「すべて」で確認できます。
最新の回の内容変更は次の回にも引き継ぎます。最新の回を保管すると新しい回の作成を止められます。

## 保存と旧版データ

- 現在の保存キー：`emberquest-v4`。localStorageに自動保存します。
- 起動時にv4がない場合、同じブラウザ・同じサイトのv3／v1を読み取って移行。
- 過去のキー自体は消しません。移行時の経験値・所持素材・装備・地域の解放を引き継ぎます。
- 旧版の大剣は大剣系統の対応段階へ、旧版の双剣は双剣系統へ変換します。
- 旧版で途中だった地域は、与えていたダメージの割合を保ちながら新しいボス遭遇へ変換。
- 旧版で完了した任務は過去の記録として引き継ぎます。v4移行前の達成報酬は取消対象に含めません。
- v4の完了取消は後続の遭遇・素材・鍛造も再計算します。成立しなくなった鍛造は解除。
- JSON復元はv4とv3のバックアップに対応。破損・不正な形式は置き換え前に拒否。
- ブラウザ・URL・端末によって保存領域は異なります。移行にはJSON書き出し／復元を利用してください。
- シークレットモード、保存容量不足、ブラウザデータ削除では保存できない／失う場合があります。

## 検証

自動テスト：
- 初回任務による斥候突破、資材回収、HPの持続、ボス撃破と即時解放。
- 同段階の大剣と双剣のダメージ一致、連撃の整数配分。
- 強化の素材消費、上位段階への継続、完了取消による依存鍛造の解除。
- 毎日／毎週の生成、重複防止、休息時に過去回を大量生成しないこと、夏時間の境界。
- JSON保存／復元、日次まとめ、翌日の一歩、旧版移行、破損データの拒否。

ブラウザQA：
- テンプレート登録、週次の選択、集中画面、初戦突破、鍛造プレビュー。
- 遠征終了、翌日の任務生成、再読み込み後の保持。
- JSONの実ファイル書き出しと復元。
- 390 × 844pxのiframeでスマホ用CSSを適用し、主目標・着手ボタン・報酬予告の初画面表示を確認。
